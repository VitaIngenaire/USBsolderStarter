WELCOME!
The USB Solder Starter is a Printed Circuit Board (PCB) Kit meant for an instructional aid for pupils of all ages to learn the basics of soldering.
Level 1 consists of a single PCB board with "through-hole" (THT) components & large pads, which are easier for beginners. Once complete, it can be inserted into a standard USB-A port to light the LED. Having various voltages and Ohm's law printed on the board, it could be used for many other lessons on basic electronics.
Level 2 adds headers and a "minibadge" board for additional through-hole practice, while also providing an introduction into surface-mount (SMD) components.
Level 3 is a more advanced minibadge, with pads to practice increasingly small components & trace cutting. This results in a glowing campfire under 0603-sized twinkling stars.
The minibadge specification is openly available, and many other designs exist for various enjoyment as achievements, trading, collectibles, or challenges.
